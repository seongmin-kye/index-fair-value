# 컨센서스 EPS 출처 정비 — 설계

날짜: 2026-11-08. 적정가 계산식은 바꾸지 않는다. 바꾸는 것은 "컨센서스 EPS 를 어디서 받아 어떻게 합치느냐"뿐이다.

## 1. 왜

- 과거 PER 은 Zacks 조정 분기 EPS(이력)로 계산한다. 미래 EPS 는 같은 잣대여야 한다.
- 지금 "Zacks" 라벨로 쓰는 Nasdaq API 연간 컨센서스는 종목에 따라 Zacks 사이트·Yahoo 보다 10~40% 낮다
  (INTC 1.04 vs 1.47/1.49, AMD 6.57 vs 7.61/8.09, MPWR·ALAB·NXPI·TSEM 도 같은 방향). 같은 3분기 실적도 Nasdaq 은 AMD 1.84·INTC 0.41,
  이력과 Yahoo 는 2.09·0.52. 중간값을 쓰는 지금 방식은 적정가를 한 방향으로 낮춘다 (SOXX 오늘 적정가 약 −4~5%).
- Yahoo 와 Zacks 사이트는 SOXX 27종목에서 중앙값 1% 차이로 같은 잣대다. 예외: ASML 은 Yahoo 분기 실적이 이력과 전부 다르다(다른 잣대),
  MTSI 는 발표 직후 Zacks 가 늦다.
- 컨센서스는 발표 뒤 2~4주 움직이는데 주 1회(토요일)만 받는다.

## 2. 출처와 역할

| 출처 | 역할 | 비고 |
|---|---|---|
| Zacks 사이트 `stock/quote/{T}/detailed-earning-estimates` | FY0·FY1 수준 (연간 컨센서스, 추정 수) | 이력과 같은 잣대 (정의상) |
| Yahoo quoteSummary earningsTrend | FY0·FY1 수준 (연간 컨센서스, 추정 수) | 잣대 검사 통과 시만 |
| Nasdaq API earnings-forecast | FY+2 이후의 성장 경로 | 수준은 재기준화 |
| WiseReport (한국 종목) | 지금과 같음 | 변경 없음 |

## 3. 합치는 규칙 (forward_per.build_rows)

1. 잣대 검사: 출처가 보고하는 최근 분기 실적을 이력 잣대(Zacks earnings-calendar 분기 실적)와 맞춘다.
   겹치는 분기가 2개 이상이고 모두 |차| ≤ 0.011 이면 통과, 하나라도 어긋나면 그 종목에서 그 출처를 뺀다.
   겹치는 분기가 2개 미만이면 판단 보류(통과로 취급). Zacks 사이트는 정의상 통과.
2. 수준 연도(FY0·FY1): 통과한 출처들의 애널리스트 수 가중 평균. `eps = [w, w]`, `n` 은 출처별 수, `src` 는 출처별 원값.
3. 그 뒤 연도: Nasdaq 값 × k. k = (수준 연도 중 Nasdaq 도 있는 마지막 연도의 가중 평균) ÷ (그 연도 Nasdaq 값). Nasdaq 과 겹치는 연도가 없으면 k = 1.
   `src = {"Nasdaq": 원값}`, `rebase = k`.
   단 k 가 0.8~1.25 밖이면 Nasdaq 은 다른 잣대(예: CRWD k≈7.3, DDOG 3.1 — GAAP 성격)로 보고 Nasdaq 만 있는 연도를 버린다.
   비율로 옮길 수 있는 것은 같은 잣대의 성장 경로뿐이다. 버린 연도는 기존 규칙대로 FY0→FY1 성장률 추정(est)이 채운다.
   (전체 갱신 실측: 514종목 k 중앙값 1.001, |k−1|>0.3 인 종목 22개.)
4. 수준 출처가 하나도 없으면 Nasdaq 원값 그대로 (k = 1) — 옛 동작으로의 fallback.
5. 성장률·thin(≤3명)·끝난 회계연도 실적·추정 연도 규칙은 지금과 같다.
6. build.py 의 `unify`(1.5배 규칙)는 없앤다. 잣대 문제는 1 에서 해결된다.

## 4. 갱신 주기

- `full`(토요일): 지금처럼 전 종목. 각 종목에 `last_report`(Zacks 마지막 발표일, ISO)와 `basis`({출처: true/false/null})를 저장.
- 새 모드 `recent`: `last_report` 가 오늘로부터 14일 이내인 종목만 컨센서스와 주가를 다시 받는다. 워크플로의 평일 22:30 UTC 종가 갱신 뒤에 돈다.
  장중 30분 갱신에는 넣지 않는다.

## 5. 스냅샷

- `data/consensus/2026-11.json` 은 옛 잣대(Nasdaq+Yahoo 중간값)라 지우고, 이번 전체 갱신이 새 잣대로 다시 만든다 (날짜는 11-08).

## 6. 하지 않는 것

- 페이지(JS) 계산·표시는 바꾸지 않는다. 페이지는 `eps·est·actual·fy·thin` 만 본다.
- 과거 이력·백테스트는 실제 EPS 를 쓰므로 변하지 않는다.
- Zacks "가장 최근 추정"은 쓰지 않는다 (평균 컨센서스가 기준).

## 7. 실패 처리

- Zacks 사이트가 막히면 Yahoo 만으로, 둘 다 막히면 Nasdaq 원값으로 (3.4). 어느 경우든 `full` 은 오류를 출력하고 계속 돈다.
